Pre-flight checklist
  • Radio menu: OPERATION SETTING → GENERAL → TUN/LIN PORT SELECT = EXT-TUNER
  • Radio menu: OPERATION SETTING → GENERAL → TUNER SELECT = EXT
  • mAT-30 connected to the TUNER/LINEAR jack with the mAT-CY cable, antenna connected to the mAT-30 output
  • Radio power set to the minimum useful for tuning - 5W or less
  • Chosen frequency ranges fall inside your license privileges
  • You've run one manual test frequency successfully before sweeping a full band
  • The band sounds dead or nearly so - listen first, and hit Stop right away if you're about to sweep across someone

Sweep settings

Dwell is a fixed wait per frequency, not an adaptive timeout - the radio can't reliably report when an external tuner like the mAT-30 has finished, so it just holds each frequency for this long before moving on. Set it to comfortably cover your tuner's typical cycle time.
